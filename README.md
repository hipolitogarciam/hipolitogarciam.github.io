# hipolitogarciam.github.io

Redirección de las direcciones antiguas a urglab.com. Las herramientas ahora viven en la
organización **Urglab** y se publican en https://urglab.com.

- `redirigir.js`: tabla de direcciones antiguas → nuevas (`MAPA`). Al mover otra herramienta
  a Urglab, añadir aquí su línea.
- `404.html` e `index.html`: cargan `redirigir.js`. GitHub Pages sirve `404.html` para
  cualquier dirección que ya no existe en esta cuenta.
- `formacion-bomberos-ucv/sw.js`: para los móviles que instalaron la formación LIFEPAK en la
  dirección antigua. Borra su copia sin conexión y los lleva a la dirección nueva.

Este repositorio tiene que ser **público** (la cuenta personal es gratuita) y no debe
contener nada más que la redirección.
